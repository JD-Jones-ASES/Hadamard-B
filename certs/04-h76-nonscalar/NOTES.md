# cert 04 — `H(76)` on a non-cyclic group, non-scalar multiplier

## Read this first: which `M` is meant

The source lane calls this instance the **non-scalar `M`** gate. In that
lane `M` is a **multiplier subgroup `M ≤ Aut(G)`** — the group of
automorphisms of `G` that the seed quadruple is required to be constant
on the orbits of. "Non-scalar" is a property of an *automorphism*: not
of the form `t ↦ c·t`.

That `M` is **not** the Gram matrix `M` of Theorem A's hypothesis (H1).
The two are unrelated objects that share a letter. This cert measures
the Theorem-A Gram explicitly and reports it: at these parameters
(`i = 1`, `s = 1`) it is `M = [[4]]`, which **is** the house form
`(4s+4)I_i − 4J_i`. This instance is therefore *not* a witness against
Gram-forcing; the repository's non-house-Gram witness is the character
twist at order 1916 (NOTE-B.md §1.2, §3.3), a different artifact.

## The claim

> The banked parameter record is a valid bordered Goethals–Seidel
> instance at `s = 1`, `i = 1`, `w = 18`, `N = 76`, on the **non-cyclic**
> group `G = ℤ₂×ℤ₃×ℤ₃` (`n = 18`), `ρ = (0,0,0)`, standard orientation.
> It satisfies the four hypotheses of **Theorem A in its general form**
> — with the Gram `M` measured off the record rather than assumed — and
> assembles to a Hadamard matrix of order 76 whose canonical SHA-256 is
> the digest pinned below.
>
> Independently: `G` is non-cyclic, and the **full stabiliser of the
> seed quadruple inside `Aut(G)`** is a group of order 2 generated by
> the non-scalar automorphism `(t₀,t₁,t₂) ↦ (t₀,t₂,t₁)`, with 12 orbits
> on `G`. `|Aut(G)| = 48`.

## Exactly which hypotheses `run.py` checks

`run.py` does **not** route this record through the house-form `H3`
(`Q Qᵀ = I₄ ⊗ ((4s+4)I_i − 4J_i)`). It implements the four hypotheses of
Theorem A as stated in NOTE-B.md §1.1, in stdlib exact integer
arithmetic, reusing the building blocks of `tools/bordered_gs.py`
(`AbelianGroup`, `coset_map`, `QuotientGroup`, `gs_array`, `mat_mul_t`,
`signs`, `assemble`) **without modifying that file**:

| | checked as |
| --- | --- |
| **(H1)** | `Q Qᵀ = I₄ ⊗ M` — all cross-superblock blocks of `Q Qᵀ` vanish; the four diagonal blocks agree; the common block `M` is `Ḡ`-invariant (`M[c,c'] = M(c−c')`) and symmetric (`M(e) = M(−e)`). **`M` is measured, not assumed**, and reported. |
| **(H2)** | `Σ_q PAF_q(t) = 4n·δ_{t,0} − M(κ(t))` for every `t ≠ 0`, using the `M` measured in (H1) — not the house value. |
| **(H3)** | `E Eᵀ + w·P Pᵀ = N·I_{4s}`. |
| **(H4)** | `E Qᵀ + P Ĉᵀ = 0`, with `Ĉ = GS(σ₀,…,σ₃; κ(ρ))` the Goethals–Seidel array of the coset sums over `Ḡ`. |

NOTE-B.md numbers the hypotheses this way. `tools/bordered_gs.py` numbers
the same four conditions `H1` = profile, `H2` = corner/row-table,
`H3` = column Gram, `H4` = coupling. This cert uses the NOTE-B.md
numbering throughout.

As a **control** the cert also runs the house-form checker
`check_record` on the same record and asserts (a) it passes and (b) the
two assemblies are identical row for row. At these parameters the house
`H3` is satisfied, so the control is expected to pass, and it does.

The multiplier claim is checked from scratch, not read off a log:
`run.py` enumerates every automorphism of `G` (all matrices `A` over the
invariant factors giving a well-defined bijective endomorphism), computes
the exact stabiliser of the seed quadruple inside `Aut(G)`, and asserts
the stabiliser is the banked group — order 2, non-scalar, 12 orbits on
`G`.

## How to re-run

From the repository root, on bare Python 3.9 or newer, stdlib only:

```
python verify/verify.py --selftest
python certs/04-h76-nonscalar/run.py
```

Runtime ≈ 0.2 s. The matrix is assembled into a temporary directory
outside the repository, verified, digest-compared, and deleted.

Exit code 0 iff every check passed and the digest matched.
